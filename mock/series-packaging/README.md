# Mock: streaming-style member area and series packaging (not product code)

Static HTML mocks for board row mer-series-packaging, for Matt's one approval before Phase 1 is built. Nothing here is served by the app or the site (GitHub Pages deploys `landing-page/` only) and this folder is not meant to be merged as product code.

- `data.js` is generated by `build-data.js` from `landing-page/courses.html` (ALL_COURSES, SERIES) and `webhook/main.py` (published dates). Course and series titles, hours, descriptions, objectives and `where` labels are real.
- The member ("Sample Member"), progress, completion dates and certificate numbers are sample data, flagged in a ribbon on every screen.
- Buttons go nowhere; no Stripe link is used.
- Covers are drawn by one SVG poster template in `mock.js` (kicker, short title, part label, line motif). Posters carry no claims.

Screens (`screens/`, deviceScaleFactor 2, desktop 1440 wide and phone 390 wide):
1. `dashboard.html`: member home: hero, CPD hours tally, topic filter, data-driven rows.
2. `series.html`: Field Work: Insulation series page.
3. `course.html` (and `?state=issued`): course page with the in-app completion panel, before and after.
4. `certificates.html`: My certificates.
5. `courses.html`: public courses page led by series cards.

Rebuild: `node mock/series-packaging/build-data.js && node mock/series-packaging/shoot.js [fontCacheDir]`.
